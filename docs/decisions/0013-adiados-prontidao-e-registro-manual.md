# ADR 0013: Adiados: questionário de prontidão para saúde e registro manual de treinos

- **Status:** Adiada
- **Data:** 2026-10-19

## Contexto

Um questionário de prontidão para saúde (ex.: PAR-Q) e o registro manual de treinos são úteis, mas não essenciais para validar o MVP com dados do Strava.

## Decisão

Adiar as duas funcionalidades. Elas não entram no escopo atual e serão reavaliadas depois do MVP.

## Consequências

- O escopo do MVP fica menor.
- Sem questionário, o app não faz triagem de saúde. O MVP deve deixar claro que não substitui orientação médica.
- Sem registro manual, só treinos sincronizados pelo Strava entram no app.
- Quando forem retomadas, cada uma ganha um ADR próprio.
